# 隐私说明

更新时间：2026-07-28

## 处理的数据

- 扩展会把用户提交的简报、约束和修改意见发送到用户配置的 Visual Prompt Compiler API。
- API 在功能开启时把生成所需内容发送给配置的 OpenAI 项目；适用该项目的 OpenAI 数据条款。
- 扩展在 `chrome.storage.local` 保存设置、最多 20 条编译结果和最多 50 条收藏。结果可能包含由简报派生的目标、假设和提示词，但不保存原始请求对象或图片预览。
- 图片预览只存在当前页面内存，刷新即消失。

## 不做的事

- 扩展不收集 OpenAI API Key；Key 只存在服务端环境变量。
- API 不持久化原始简报、提示词、固定文案或图片；日志只包含请求 ID、模型标识、版本、状态、耗时和用量元数据。
- 当前没有账号、广告、分析 SDK、崩溃上报或其他遥测。

## 用户控制

用户可在侧边栏清空本地历史；卸载扩展会按 Chrome 的行为移除扩展本地数据。服务部署者负责说明其 OpenAI 项目、日志保留期、访问控制和删除流程。
